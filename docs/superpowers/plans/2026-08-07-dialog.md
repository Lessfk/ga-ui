# GaDialog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Element Plus `ElDialog` 基础上交付一个无内置按钮、支持常用类型化 Props、完整原生生命周期事件和 `$attrs` 透传的 `GaDialog` 基础组件。

**Architecture:** `GaDialog` 作为受控的轻量包装层，将精选 Props、插槽和事件显式映射到 `ElDialog`，其余能力通过 `$attrs` 透传。组件自身不管理业务状态或提交逻辑，只暴露内部 `dialogRef`；公共导出、构建验证、README 和 Playground 同步更新。

**Tech Stack:** Vue 3 `<script setup>`、TypeScript 5.8、Element Plus 2.14.3、SCSS、Vitest、Vue Test Utils、Vite 6、pnpm workspace。

---

## 实施约束

- 设计依据：`docs/superpowers/specs/2026-08-07-dialog-design.md`。

- [ ] **Step 4：实现最小可用的 GaDialog**

将 `packages/ui/src/base/components/dialog/src/index.vue` 写为：

```vue
<template>
  <ElDialog
    ref="dialogRef"
    v-bind="$attrs"
    class="ga-dialog"
    :model-value="props.modelValue"
    :title="props.title"
    :width="props.width"
    :top="props.top"
    :fullscreen="props.fullscreen"
    :append-to-body="props.appendToBody"
    :destroy-on-close="props.destroyOnClose"
    :center="props.center"
    :align-center="props.alignCenter"
    :draggable="props.draggable"
    :show-close="props.showClose"
    :close-on-click-modal="props.closeOnClickModal"
    :close-on-press-escape="props.closeOnPressEscape"
    :before-close="props.beforeClose"
    @update:model-value="handleUpdateModelValue"
    @open="handleOpen"
    @opened="handleOpened"
    @close="handleClose"
    @closed="handleClosed"
    @open-auto-focus="handleOpenAutoFocus"
    @close-auto-focus="handleCloseAutoFocus"
  >
    <template v-if="slots.header" #header="scope">
      <slot name="header" v-bind="scope" />
    </template>

    <slot />

    <template v-if="slots.footer" #footer>
      <slot name="footer" />
    </template>
  </ElDialog>
</template>

<script setup lang="ts">
import { ElDialog } from 'element-plus'
import type { DialogInstance } from 'element-plus'
import { ref, useSlots } from 'vue'

import type { GaDialogEmits, GaDialogProps } from '../types'

defineOptions({
  name: 'GaDialog',
  inheritAttrs: false,
})

const props = withDefaults(defineProps<GaDialogProps>(), {
  modelValue: false,
  title: '',
  fullscreen: false,
  appendToBody: false,
  destroyOnClose: false,
  center: false,
  alignCenter: undefined,
  draggable: undefined,
  showClose: true,
  closeOnClickModal: true,
  closeOnPressEscape: true,
})

const emit = defineEmits<GaDialogEmits>()
const slots = useSlots()
const dialogRef = ref<DialogInstance>()

const handleUpdateModelValue = (value: boolean) => {
  emit('update:modelValue', value)
}

const handleOpen = () => emit('open')
const handleOpened = () => emit('opened')
const handleClose = () => emit('close')
const handleClosed = () => emit('closed')
const handleOpenAutoFocus = () => emit('open-auto-focus')
const handleCloseAutoFocus = () => emit('close-auto-focus')

defineExpose({
  dialogRef,
})
</script>

<style lang="scss">
@use '../style/index.scss';
</style>
```

## GaDialog

`GaDialog` 是 `ElDialog` 的轻量通用封装。它通过 `v-model` 控制显示状态，提供常用 Dialog Props、原生生命周期事件和 `default`、`header`、`footer` 插槽。组件不内置确认或取消按钮；操作区由使用方通过 `footer` 插槽定义。

### 基础用法

```vue
<template>
  <ElButton type="primary" @click="visible = true">
    打开弹窗
  </ElButton>

  <GaDialog v-model="visible" title="用户详情" width="520px">
    <p>这里放置弹窗主体内容。</p>
  </GaDialog>
</template>

<script setup lang="ts">
import { ElButton } from 'element-plus'
import { ref } from 'vue'
import { GaDialog } from 'ga-ui-plus/base'

const visible = ref(false)
</script>
```

### 自定义头部和底部

`header` 插槽原样提供 Element Plus 的 `close`、`titleId` 和 `titleClass`；`footer` 没有默认内容，按钮和点击行为完全由使用方决定。

```vue
<template>
  <GaDialog v-model="visible" width="560px">
    <template #header="{ close, titleId, titleClass }">
      <div class="dialog-header">
        <span :id="titleId" :class="titleClass">编辑用户</span>
        <ElButton link type="primary" @click="close">关闭</ElButton>
      </div>
    </template>

    <p>填写或展示业务内容。</p>

    <template #footer>
      <ElButton @click="visible = false">取消</ElButton>
      <ElButton type="primary" @click="save">保存</ElButton>
    </template>
  </GaDialog>
</template>

<script setup lang="ts">
import { ElButton } from 'element-plus'
import { ref } from 'vue'
import { GaDialog } from 'ga-ui-plus/base'

const visible = ref(true)

function save() {
  visible.value = false
}
</script>
```

### 关闭拦截和属性透传

`beforeClose` 沿用 Element Plus 的 `done` 回调机制。未显式声明的 Dialog 属性和监听器会通过 `$attrs` 透传，例如 `modal`、`lock-scroll`、`modal-class`、`z-index`。`beforeClose` 内部的业务错误由使用方处理，`GaDialog` 不捕获或转换异常。

```vue
<template>
  <GaDialog
    v-model="visible"
    title="关闭拦截"
    :before-close="handleBeforeClose"
    :lock-scroll="true"
    modal-class="user-dialog-modal"
  >
    <p>点击遮罩、关闭按钮或按 Esc 时会先询问。</p>
  </GaDialog>
</template>

<script setup lang="ts">
import type { DialogBeforeCloseFn } from 'element-plus'
import { ref } from 'vue'
import { GaDialog } from 'ga-ui-plus/base'

const visible = ref(true)

const handleBeforeClose: DialogBeforeCloseFn = (done) => {
  if (window.confirm('确定关闭弹窗吗？')) {
    done()
  }
}
</script>
```

### GaDialog Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | `boolean` | `false` | 显示状态，支持 `v-model` |
| `title` | `string` | `''` | 默认头部标题 |
| `width` | `string \| number` | Element Plus 默认值 | 弹窗宽度 |
| `top` | `string` | Element Plus 默认值 | 距离视口顶部的距离 |
| `fullscreen` | `boolean` | `false` | 是否全屏 |
| `appendToBody` | `boolean` | `false` | 是否将 Dialog 挂载到 `body` |
| `destroyOnClose` | `boolean` | `false` | 关闭后是否销毁主体内容 |
| `center` | `boolean` | `false` | 是否居中显示头部和底部内容 |
| `alignCenter` | `boolean` | Element Plus 默认行为 | 是否在视口内水平、垂直居中 |
| `draggable` | `boolean` | Element Plus 默认行为 | 是否允许拖拽 |
| `showClose` | `boolean` | `true` | 是否显示关闭按钮 |
| `closeOnClickModal` | `boolean` | `true` | 点击遮罩是否关闭 |
| `closeOnPressEscape` | `boolean` | `true` | 按 Esc 是否关闭 |
| `beforeClose` | `DialogBeforeCloseFn` | `undefined` | 关闭前拦截函数 |

### GaDialog Events

| 事件 | 参数 | 说明 |
| --- | --- | --- |
| `update:modelValue` | `(value: boolean)` | 更新 `v-model` |
| `open` | `()` | Dialog 开始打开 |
| `opened` | `()` | 打开动画结束 |
| `close` | `()` | Dialog 开始关闭 |
| `closed` | `()` | 关闭动画结束 |
| `open-auto-focus` | `()` | 打开后完成自动聚焦 |
| `close-auto-focus` | `()` | 关闭后完成自动聚焦恢复 |

### GaDialog Slots

| 插槽 | 作用域 | 说明 |
| --- | --- | --- |
| `default` | 无 | 弹窗主体内容 |
| `header` | `{ close, titleId, titleClass }` | 自定义头部，作用域来自 Element Plus |
| `footer` | 无 | 自定义底部；默认不渲染任何按钮 |

### GaDialog 实例

组件实例暴露 `dialogRef`，其类型为 Element Plus `DialogInstance | undefined`。高级场景可以访问 `handleClose`、`resetPosition` 等底层实例能力。

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { GaDialog, type GaDialogExpose } from 'ga-ui-plus/base'

const dialogInstance = ref<GaDialogExpose>()

function closeDialog() {
  dialogInstance.value?.dialogRef?.handleClose()
}
</script>
```

更多低频能力参见 [Element Plus Dialog 文档](https://element-plus.org/zh-CN/component/dialog.html)。
